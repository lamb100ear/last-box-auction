# 声音资源说明

本目录存放《再拍最后一箱！》的原创背景音乐。

## 曲目

| 文件 | 使用场景 | 氛围 |
| --- | --- | --- |
| `menu_noir_loop.wav` | 开始菜单、账户初始化 | 低沉黑胶、悬疑爵士、缓慢 |
| `day_market_loop.wav` | 正常经营日 | 轻快但带有不安感的旧电脑经营氛围 |
| `case_file_loop.wav` | 案件文件夹、主线调查 | 更暗、更稀疏、带有档案调查感 |

## 播放规则

- 浏览器首次用户操作后才开始播放，符合自动播放限制。
- 菜单和桌面经营会自动切换曲目。
- 进入案件文件夹或主线阶段后切换为调查曲。
- 任务栏提供 `BGM 开 / BGM 关` 按钮。
- 切换曲目时使用短暂淡出和淡入。

## 生成

当前音频由项目内脚本 `tools/generate_bgm.mjs` 使用本地波形合成生成，不依赖外部素材或采样包。

重新生成：

```powershell
node tools/generate_bgm.mjs
```

音频为项目原创资源，可用于本项目及其部署版本。
