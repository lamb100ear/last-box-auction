## 1. 文档定位

本文件是检视小游戏、物品常规操作和伪造玩法的最终方案总表。

之前已经讨论但被移除的内容包括：

- 依赖文字选项的小游戏。
- 按顺序点击接缝或零件的固定流程。
- 每件物品强制拥有全部操作。
- 单纯的“伪造后售价提高”规则。
- 放大镜只是装饰图标、没有真实放大效果。
- 继续使用用户生成物品贴图参与检视操作。

当前方案以美术图层、工具光标、拖拽和真实信息覆盖为核心。

- 万物通参考：显示价格、市场趋势、关键词资料和可核对事实。

## 3. 常规操作抽取

常规操作池只有三项：

1. 清洁。
2. 电路修复。
3. 放大镜检查。

每件物品根据模板、状态、来源、外观和隐藏信息，随机配对 `2～3` 项操作。抽取结果在物品生成时确定并写入存档。

规则：

- 状态受损、污渍或发霉时提高清洁权重。
- 存在螺丝、外壳、主板、机械零件或维修历史时提高电路修复权重。
- 存在标签、刻印、来源矛盾或隐藏文字时提高放大镜检查权重。
- 状态完好、无电路结构的普通物品可以只获得两项操作。
- 每件物品至少获得两项，不能只显示一个图标。
- 主体问题必须至少对应一项操作。

## 4. 清洁玩法

### 美术图层

```text
物品基础图
污渍遮罩层
灰尘粒子层
氧化或受潮层
隐藏刻印层
完成高光层
```

### 操作方式

1. 点击清洁刷图标。
2. 鼠标光标变为清洁刷。
3. 在物品表面按住并拖动。
4. 污渍遮罩沿拖动轨迹消失。
5. 被遮挡的刻印、编号、姓名或品牌标识自然出现。
6. 过度擦拭会留下划痕，降低状态。

### 视觉反馈

- 污渍被擦除，不使用“清理 1/3”文字。
- 灰尘以粒子掉落。
- 纸面、金属、织物和木质使用不同污渍纹
理。
- 划痕直接保留在物品图上。

### 美术需求

- 每个物品模板准备 2 到 4 张污渍遮罩。
- 清洁刷需要工具栏图标、鼠标光标、擦拭轨迹和粒子。
- 不同材质使用不同清洁反馈。

## 5. 电路修复玩法

电路修复不再拆成多个小游戏，而是包含拆螺丝、拆外壳、取零件、检查零件、组装和电路连接。

### 美术图层

```text
外壳层
四颗独立螺丝层
外壳盖板层
主板层
线路节点层
可拆零件层
幽灵组装槽位层
完成通电高光层
```

### 操作流程

1. 点击电路修复图标。
2. 四颗螺丝独立高亮。
3. 鼠标变为螺丝刀，点击或拖动螺丝。
4. 螺丝旋转并落入零件托盘。
5. 四颗螺丝全部卸下后，拖动外壳盖板向外移动。
6. 外壳打开后，鼠标自动切换为镊子或允许选择镊子。
7. 拖动主板、线路或接口零件到托盘。
8. 检查烧黑节点、断线和错误接线。
9. 将零件拖回幽灵轮廓，正确时自动吸附。
10. 重新安装盖板和螺丝，线路通电。

### 故障表现

- 螺丝没有拆完时，外壳会卡住并抖动。
- 零件放错位置时无法完全贴合，留下缝隙。
- 线路连接错误时节点闪烁。
- 过度用力会损坏螺丝或零件。

### 美术需求

- 外壳、盖板、主板和每颗螺丝必须分开。
- 每颗螺丝需要正常、旋转、卸下和遗失状态。
- 托盘需要空槽、正确槽、错误槽和已完成状态。
- 线路需要断电、错误、通电和闪烁状态。

## 6. 放大镜检查

放大镜需要真实放大物品局部，不是装饰图标。

### 实现方式

- 物品基础图和放大图同时存在。
- 放大镜圆形区域使用裁剪蒙版显示放大图。
- 放大倍率使用 `1.8×` 到 `2.5×`。
- 放大区域跟随鼠标移动。
- 放大镜边框、玻璃高光和阴影为独立美术层。

### 可以发现的真实信息

- 真实年代。
- 真实状态。
- 真实来源。
- 维修历史。
- 是否有完整来源。

### 具体表现

- 标签下面的旧胶痕。
- 被覆盖的年份、名字和编号。
- 纸张纤维、印章压痕和墨迹年代。
- 螺丝、主板和材料的新旧差异。
- 缺失零件的原始轮廓。
- 原包装封条与物品是否年代一致。

放大镜发现的是真实信息。真实信息不会被伪造品直接删除，只能被后续伪造层覆盖。

## 7. 伪造页面

补充标签包含在伪造操作中，主界面不再单独显示“补充标签”按钮。

```text
┌────────────────────────────────────────────────────────────┐
│ 返回   伪造工作台                                          │
├────────────────────────────────┬───────────────────────────┤
│ 左侧物品视图                   │ 真实信息                  │
│ 放大镜跟随鼠标放大局部         │ 年代/状态/来源/维修/来源完整性│
│                                ├───────────────────────────┤
│ 物品上的缺口和矛盾区域         │ 四种伪造材料              │
│                                │ 空白标签 / 替代材料       │
│                                │ 虚假包装 / 来源文件       │
│                                ├───────────────────────────┤
│                                │ 伪造预览与矛盾表现        │
└────────────────────────────────┴───────────────────────────┘
```

### 伪造原则

- 伪造不是简单提高售价，而是覆盖真实信息。
- 真实信息可能压低价格。
- 伪造材料提升的是买家感知，不改变真实事实。
- 买家核验时会根据核验重点进行对比。
- 伪造后的物品外观保持伪造层，不能只改变数值。

## 8. 真实信息范围

每件物品只保留以下五项真实信息：

```js
{
  trueYear,
  condition,
  source,
  repairHistory,
  hasCompleteProvenance
}
```

### 真实年代

- 物品实际生产年代。
- 与标签或卖家描述不一致时会产生核验风险。

### 状态

- 完好、磨损、受潮、破损、缺件等。
- 影响价值和买家接受程度。

### 来源

- 机场清仓、私人寄售、旧宅清仓、灰色渠道等。
- 负面来源会拉低价格或增加调查风险。

### 维修历史

- 是否维修过。
- 是否更换过零件。
- 维修技术是否粗糙。

### 是否有完整来源

- 是否拥有可以连续追溯的来源记录。
- 没有完整来源时，高价买家的信任降低。

## 9. 四种伪造材料

| 材料 | 覆盖的真实信息 | 主要作用 | 核心操作 | 主要破绽 |
| --- | --- | --- | --- | --- |
| 空白标签 | 年代、来源 | 伪造身份和出处 | 拖动标签、旋转、对齐、压平 | 旧胶痕、字体年代、刻印位置 |
| 替代材料 | 状态、维修历史 | 补全缺件，伪装原装状态 | 拖入缺口、旋转、融合 | 材质纹
理、接缝、新旧磨损 |
| 虚假包装 | 状态、来源完整性 | 提高完整度和收藏感 | 折叠、贴封条、压平 | 纸张年代、封条、包装数量 |
| 来源文件 | 来源、来源完整性 | 提高买家信任和历史连续性 | 拖动日期、印章、文件类型 | 日期、印章、纸张和文件格式 |

### 空白标签

- 覆盖物品原本的普通来源或不利年代。
- 可以填写虚构姓名、年份、私人收藏和旧品牌标记。
- 只影响外观和买家感知，不改变真实年代。

### 替代材料

- 用于补全缺失零件或破损结构。
- 可以改变买家对状态和维修历史的判断。
- 放大镜可以发现材质纹理和磨损不一致。

### 虚假包装

- 让普通物品看起来像有原包装的收藏品。
- 可以遮住标签边缘和物品损伤。
- 包装与物品年代不一致时风险较高。

### 来源文件

- 补全来源和交易历史。
- 主要影响高价买家和审核型买家。
- 需要与真实年代、标签和物品材质匹配。

---

## 10. 放大镜与伪造信息联动

放大镜负责发现真实信息，伪造材料负责覆盖不利信息。

| 放大镜发现 | 不利影响 | 可使用的伪造方式 |
| --- | --- | --- |
| 真实年代太新 | 无法作为古董高价出售 | 空白标签、来源文件 |
| 真实来源为灰色渠道 | 买家信任和调查风险差 | 来源文件、虚假包装 |
| 存在明显维修 | 收藏价值下降 | 替代材料、虚假包装 |
| 缺少完整来源 | 高价买家拒绝购买 | 来源文件 |
| 零件缺失或损坏 | 状态价值下降 | 替代材料 |

操作流程：

1. 拖动放大镜检查物品。
2. 发现真实信息。
3. 选择伪造材料。
4. 把材料拖到对应区域。
5. 将标签、印章、日期和零件拖到槽位。
6. 伪造预览显示矛盾和瑕疵。
7. 完成伪造并保留外观状态。

---

## 11. 买家核验

不同买家检查不同信息：

- 普通买家：外观、包装、标签是否整洁。
- 收藏买家：真实年代、来源、完整来源。
- 审核型买家：标签、文件、印章和纸张年代。
- 鉴定师：材质、维修历史、零件磨损。

对应关系：

- 空白标签对应年代和来源核验。
- 替代材料对应状态和维修核验。
- 虚假包装对应状态和完整度核验。
- 来源文件对应来源和历史核验。

## 12. 价格与风险

```text
最终报价 =
真实价值
+ 正面真实信息加成
- 负面真实信息扣减
+ 伪造信息感知价值
- 矛盾程度风险扣减
```

### 可选择策略

- 如实出售：价格稳定，风险低。
- 只覆盖部分负面信息：价格提升有限，风险较低。
- 四种伪造组合：价格最高，核验和调查风险最高。

实现原则：

- 操作结果写入物品实例。
- 伪造层和真实信息分开保存。
- 读档后污渍、零件、标签和包装状态不能重置。
- 买到物品后随机配对 2 到 3 项常规操作。
- 伪造页面不创建新窗口。

## 15. 验收标准

- 常规物品每件随机获得 2 到 3 项操作。
- 常规操作不依赖文字选项或顺序点击。
- 清洁通过污渍遮罩擦除完成。
- 电路修复包含螺丝、壳体、零件和组装。
- 放大镜具有真实局部放大效果。
- 放大镜可以发现五项真实信息。
- 补充标签包含在伪造页面中。
- 四种伪造材料分别覆盖不同类型真实信息。
- 伪造材料可以拖拽、旋转、贴合和压入槽位。
- 伪造后物品保留伪造层外观。
- 买家核验能够按不同类型检查对应伪造信息。
